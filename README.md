### 简单介绍
毕业设计，基于RK3506的远程图像采集系统，本仓库存放板卡端程序和视频中转服务器脚本
板卡推流，服务器中转视频同时接受客户端指令，板卡可以从服务器拿到指令来改变编码参数
### 工程结构
- **img_trans_server:**
`server.py`视频服务器脚本，使用mediaMTX，以及远程指令的接受的函数
`client.py`远程指令客户端脚本，用于发送单条指令，主要是测试

- **launcher:** 程序的GUI启动器，采用LVGL9，设置完程序启动参数后构造指令并启动程序

- **linuxDemo:** 文件名由于一开始没起好，但是里面放的是核心程序，就是板卡上运行的那个，
程序：cmake文件支持编译为多线程/单线程/颜色转换测试/远程指令测试这四个程序，具体看cmake文件。
脚本：有性能测试脚本，快速启动脚本（start_stream），以及板卡的自启动脚本（我在里面放了开机打开启动器）

- **test:** 主要是一些独立的功能测试程序，USB摄像头捕获，显示，测试V4L2。
`video_benchmark`批量测试视频编码能力
`delay_meter.py`OCR方式测试端到端延迟的脚本

其他的是与编译环境相关的内容，可以忽略

### 编译
编译都用cmake，arm交叉编译
